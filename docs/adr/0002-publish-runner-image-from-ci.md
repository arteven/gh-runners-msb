# Publish the Runner image from CI; the extension never builds images

The original script built the Runner image on the host with Docker and imported it with `msb load`. That can't work on the remote Backend, where image loading is local-only and the cloud only pulls from a reachable registry. On local it broke because msb bypasses its cache whenever the host holds credentials for the image's registry. So this repo's CI publishes a public multi-arch image at `ghcr.io/arteven/gh-runners-msb`, which both Backends pull, and the extension carries no Dockerfile, build step or `--rebuild-image`. The default reference is a floating Image contract tag (`:1`), rebuilt daily when actions-runner releases. The Pool refreshes it once per Pool start, because JIT runners can't disable self-update, so a stale runner version would cost a download on every Runner boot. Image and extension releases are independent, linked only by the contract major version. `--image` remains for custom images, used as given with `if-missing`.
